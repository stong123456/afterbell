# AskStone: Thesis Memory

The homepage now focuses on saving a trading thesis and revisiting its evidence. Existing market, research, BYOK, and capsule routes remain available. Existing browser storage keys are preserved.

## Demonstration
1. Write an actual thesis, ticker, and horizon. Use one assumption per line.
2. Review the sentence-based draft and save it. All assumptions start unverified.
3. Open an assumption, choose a source, read it, and record why it supports or challenges the assumption. A review preserves before/after states, source and timestamp.
4. Refresh evidence: What Changed lists asset-related source events published since the thesis was saved. Old news and future timestamps are excluded. A matching ticker is a lead, not an AI finding.
5. Use Challenge My Thesis to send the saved assumptions with a selected source into the existing rule/BYOK research flow. Explicitly choose/configure a model for AI analysis.
6. Save a token-price baseline for the asset and a chosen reference token. Refresh later to compare return differences only when both newer quotes are aligned and fresh.

## Boundaries
- Local browser storage, JSON export; no accounts, cloud sync, unattended monitoring, push notifications, or trusted timestamp attestations.
- Thesis Health is evidence coverage and user-confirmed status, not a numeric predictive score. Draft splitting and asset matching are deterministic, not model extraction or semantic evidence matching.
- Market Disagreement is a raw token-return difference, not beta adjustment, US-close basis, historical analog forecast, or a priced-in score.
- No fabricated historical demonstrations are inserted into the real evidence feed.
- 34 automated checks passed. Browser verified save, evidence-linked review, actual price baseline and handoff to challenge. Live model inference was not tested without a user key.
